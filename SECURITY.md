# Security Policy

## 安全问题

请不要使用公开 Issue 报告安全问题。

请打开本仓库的 **Security** 页面，选择 **Report a vulnerability**，通过 GitHub
私密漏洞报告提交问题。请说明受影响版本、复现步骤、实际影响，以及能够帮助定位问题的
日志或截图。请勿包含账号密码、私钥或其他敏感凭据。

普通功能问题和建议请使用公开 Issues。

## Security reports

Do not report security vulnerabilities in public issues.

Open this repository's **Security** page, choose **Report a vulnerability**,
and submit the report through GitHub private vulnerability reporting. Include
the affected version, reproduction steps, impact, and relevant logs or
screenshots. Do not include passwords, private keys, or other credentials.

Use public Issues for ordinary bugs and feature requests.
